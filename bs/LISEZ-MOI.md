# Bulletins Scolaires — dossier prêt pour OpenCode

1. Dézipper dans le dossier du projet.
2. Mettre le logo et les exemples de bulletins dans `docs/assets/`.
3. Lancer OpenCode dans ce dossier.
4. Coller le contenu de `prompts/phase-0-analyse.md`, puis valider.
5. Enchaîner phase 1 → 8, une à la fois, en validant chaque rapport.

`AGENTS.md` est lu automatiquement par OpenCode : il contient les règles permanentes.
