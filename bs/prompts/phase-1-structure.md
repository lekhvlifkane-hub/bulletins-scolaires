# Phase 1 — Structure technique
Crée `frontend/` (Tauri 2 + Vite + React + TS + Tailwind + shadcn/ui) et `backend/` (Express + TypeScript + Prisma + swagger-ui-express), PostgreSQL, `docker-compose.yml` (db + backend), `.env.example`, `.gitignore`, `README.md` (installation Windows pas à pas).
Critères : `docker compose up` démarre la base et le backend ; `/api/docs/` répond ; le frontend (`npm run tauri dev`) affiche une page d'accueil avec le logo ; tests de base (Vitest + Supertest côté backend, Vitest côté frontend) passent.
Rapport puis arrêt.
